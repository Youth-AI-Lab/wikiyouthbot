Cette version publique répond à partir de la base construite par le groupe. Pour poser des questions libres, ouvrez le fichier en local avec votre propre clé API.

Le robot du futur

Voici Superbot en vrai : le robot que le groupe imagine pour aider les élèves dans les établissements. Il fait 50 cm de large, il a des bras à câlins, une veilleuse, une boîte à mouchoirs, un bras téléphone pour appeler les secours et un sac à dos distributeur.

Le schéma original dessiné par le groupe : vue de face, vue de côté, et le choix entre roulettes ou roue d'hoverboard.
